# Discrete_Math_Project20262
The practical part of the discrete math project for the 20262 semester at Javeriana Cali university.

The idea is for you to define the methods in solution.py

The file struct.py is mainly to define the interface of your code. Please write your code taking into account that interface.

The file main.py is to read the files in /tests/, which where generated by my personal solution. The files run_tests.sh and w_run_tests.cmd are to automate the invocation of main.py for all files in /tests/ in linux and windows (respectively).

I think all other things should be written in the pdf that explains the project.
